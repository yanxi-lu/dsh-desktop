# dsh-desktop

DeepSeek Harness(`dsh`)的 Windows 桌面套壳:一键启动、更新、重启与托盘驻留。

当前版本 **0.5.0**，新增分栏工作台。功能范围、验证记录及限制见 [0.5.0 交付说明](docs/release-0.5.0.md)，安装包和校验文件见 [GitHub Releases](https://github.com/yanxi-lu/dsh-desktop/releases)。

Harness 官方上游:[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)。

## 功能

- 一键启动:自动拉起本机 `dsh web --no-open`(127.0.0.1:3080)并在桌面窗口中使用
- 桌面一键启动:安装器自动创建“DeepSeek Harness”桌面图标和开始菜单快捷方式
- 官方版本检查:启动后查询 DeepSeek 官方 npm `latest` 版本,发现新版时在控制栏提示
- 版本列表与切换:展示官方 npm 已发布版本,可选择指定版本安装、重装或回退
- 一键安装/更新 Harness:安装官方 npm 包 `@deepseek-ai/dsh@latest`,完成后自动恢复服务
- 预发布版启动兼容:自动读取 Harness 0.1.2+ 输出的一次性 Token URL,兼容旧版裸地址且不把 Token 发送到桌面控制页
- 可视化用量统计:提供调用次数、实际总 Tokens、缓存命中率、会话数、费用概览,以及按小时/日期趋势、模型统计、会话统计和可分页的最近调用
- 官方账户余额:自动复用 Harness 已配置的 DeepSeek Key,展示总余额、充值余额、赠送余额和账户可用状态;Key 不进入页面
- 分时与自定义估价:按每次调用的时间和实际模型自动套用官方价格,也可固定高峰/空闲档或设置本机自定义单价
- Node.js 一键安装:目标主机未安装 Node.js 时,可通过 Windows Package Manager 一键安装官方 Node.js LTS
- 可见安装进度:首次安装下载内容较多时每 5 秒更新状态,可随时取消,最长等待 15 分钟
- 首次启动耐心等待:Harness 初次初始化可能超过 30 秒,桌面壳最多等待 120 秒并持续显示用时
- 双重重启:可单独重启 Harness 服务,也可重启整个桌面应用
- 独立控制栏:即使 Harness 页面异常,顶部更新/重启按钮仍可操作
- 首次引导:未装 dsh/Node 时显示引导页,可一键安装或复制安装命令
- 托盘驻留:关闭窗口后服务在后台运行,托盘可重新打开;「退出」会连同 dsh 进程树一起结束
- 单实例:重复启动只会聚焦已有窗口
- 崩溃恢复:dsh 意外退出时弹窗提示,可一键重启服务
- 分栏工作台:总览、用量与费用、会话、插件、更新与诊断、设置分别加载；支持浅色、深色和跟随系统
- 预算提醒:每日/月度预算 80% 和 100% 提醒、官方余额下限、高费用会话；支持免打扰和持久化去重
- 会话管理:本地名称、标签、项目分类、搜索与排序；用量详情联动筛选；官方会话归档/恢复
- 插件中心:真实已安装清单、启停/卸载、npm 发现/版本检查、收藏、安装前官方识别、变更前本机配置备份
- 安全恢复:新版本独立安装，不覆盖系统全局 Harness；升级前完整数据快照，恢复时创建副本并保留新版数据
- 运行诊断:环境、端口进程、目录、网络及脱敏错误分类；支持更换可用端口、重选工作文件夹和导出报告
- 统计导出:按当前筛选导出全部调用或模型/会话/概览 CSV/JSON，而非只导出可见页
- 设置备份:主题、预算、价格、会话标签和收藏可备份恢复；费用方案不改动 Key 或官方运行配置

## 安装

1. 可预先安装 Node.js(https://nodejs.org);若未安装,首次启动页可点击“一键安装 Node.js LTS”
2. 可预先安装 dsh:`npm install -g @deepseek-ai/dsh`;也可启动桌面壳后点击“一键安装/更新 dsh”
3. 从 [GitHub Releases](https://github.com/yanxi-lu/dsh-desktop/releases/latest) 下载 `dsh-desktop-setup-x.y.z.exe`,安装完成后双击桌面“DeepSeek Harness”图标即可

> 安装包未做代码签名。请核对来源与 SHA-256；不确定来源时不要忽略系统安全提示。

## 图标

应用图标与托盘图标来自项目根目录的高清源图(2048×2048 鲸鱼娘 PNG)。
`npm run icon`(scripts/gen-icon.ps1)会从源图重新生成:

- `assets/icon.ico` — 多尺寸 ICO(16~512),嵌入 exe、安装包与桌面/开始菜单快捷方式
- `assets/icon.png` — 1024×1024 应用 PNG
- `assets/tray.png` — 32×32 托盘图标

本项目为非官方套壳,与 DeepSeek 无隶属关系。


## 更新机制

- **版本来源**:官方 npm 包 `@deepseek-ai/dsh` 的已发布版本与 dist-tags；`latest` 不等同于稳定版。更新中心区分 Alpha/RC/Release，并链接对应官方 GitHub 发布说明。仅有 Git 标签、未发布到 npm 的版本不能直接安装。
- **更新 Harness**:先在桌面壳应用数据目录中独立下载、校验 npm 包及可执行版本，再停止服务、备份完整 `DSH_HOME`、切换并等待服务就绪。不会覆盖原有全局安装。下载期间旧服务继续运行，检测到任务运行时可排队，支持取消排队与安装。
- **恢复升级前快照**:升级失败时尝试恢复旧安装和独立数据副本；也可在更新中心主动恢复。升级后新增数据保留在原目录，不删除、不自动合并到旧快照。备份包含凭据，仅留在本机应用数据目录；请保护好该目录并预留足够磁盘空间。
- **链接与失败保护**:内部 pnpm 目录链接在副本中重新定位，不指向原数据；外部/循环/文件链接不自动遍历。遇到无法安全复制或空间不足时取消切换，不自动删除备份。备份和旧安装会占用磁盘，目前没有自动清理策略。
- **桌面壳自身更新**:与 Harness 更新分开。本版没有启用壳自动更新；需要配置所属发布渠道、签名与安装包校验后另行交付。
- **为什么不直接 git pull**:官方源码运行还需要 Git、pnpm、依赖安装和完整构建;普通用户使用官方 README 推荐的 npm 发布包更稳定。Git 仓库只作为官方源码上游,不作为终端用户的运行目录。

## 用量与预估价格

- **数据来源**:只从 Harness 本机会话日志提取时间、Provider、模型和 usage 元数据,不返回或展示提示词、回复正文、工具参数、工作目录或 API Key。
- **统计范围**:默认查询今天,支持近 7 天、近 30 天和自定义起止日期,并可按 Provider/模型筛选。概览展示调用次数、实际总 Tokens、缓存命中率、涉及会话和预估费用。
- **统计明细**:趋势图今天按小时、其他范围按日期展示四类 Token 与费用；最近调用后台分页，每页 10/20/50/100 条。会话管理可搜索本地名称/标签/项目并进入单会话费用详情；加载官方标题需要在设置中单独开启。不索引提示词或回答正文，也不虚构没有数据支持的 HTTP 成功率或响应耗时。
- **统计性能**:日志读取、解压和汇总在独立工作线程执行。首次打开建立索引,后续仅处理新增或变化的日志;索引保存在应用数据目录的 `usage-cache`,重启后可复用。缓存仅包含用量元数据,不含对话正文、工具参数、工作目录或密钥;缓存损坏会自动重建。快速切换筛选条件会合并查询,相同趋势不会重复绘制。
- **图表实现**:趋势图使用随安装包本地分发的 Apache ECharts 6.1.0,支持双轴、平滑曲线、悬浮明细、图例开关、滚轮缩放和窗口自适应,不依赖在线 CDN。第三方许可证随图表文件一同保留。
- **日志适配与完整性**:兼容已核对的 V0–V4 日志及 V4 compact stream；同一目录只读取最高代际日志。流式/最终 usage 按同一调用替换，重试独立计数，分叉继承的历史不重复计数。损坏行、无法读取、未知格式会标记不完整。更新与诊断页可查看耗时、缓存占用和重建索引；重建不删除会话日志。
- **历史估价**:按提供商、实际模型、调用时间及规则生效区间匹配，支持已核对的 V4、V4.1 Flash 与别名。默认保留历史价格；“按现价模拟”明确标注，不冒充历史账单。未知模型/提供商或缺少历史依据的区间标为待定价，不静默套用 Flash 单价。
- **官方分时价格**:北京时间工作日 9:00–12:00、14:00–18:00 为高峰，其余时段、周末及已核对的 2026 法定节假日为空闲时段。未维护的年度会提示节假日资料不完整。
- **自定义价格**:支持 Provider/完整模型名、生效起止时间、命中/未命中/输出“元/百万 Tokens”单价，拒绝重叠区间。也保留明确标注的全局自定义单价。按模型规则优先于全局规则，自定义规则不会被内置官方规则覆盖。
- **价格来源**:[DeepSeek API 官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[更新日志](https://api-docs.deepseek.com/zh-cn/updates/)、[9 月 10 日公告](https://api-docs.deepseek.com/zh-cn/news/news260910/)。规则版本 `2026-09-24.1`，核对日期 `2026-09-24`。本版随安装包更新规则，不在后台自动抓取并覆盖价格。
- **对比与导出**:与紧邻的前一等长时段对比，展示具体对比时间；费用不完整时不显示误导性增长率。导出包含币种、时区、筛选、规则版本、自定义价格快照、完整性及更新时间；CSV 防公式注入。
- **重要说明**:估算值不是官方账单。非 DeepSeek 模型、第三方代理加价、失败重试、分叉或导入会话都可能造成差异;实际费用以服务商账单为准。

性能回归:构建后可运行 `node scripts/check-usage-performance.cjs`,只读本机日志,对比首次建索引、重复查询、重启缓存以及工作线程响应性。`electron scripts/smoke-usage-ui.cjs` 使用独立隐藏窗口和合成日志验证分页、筛选合并及图表更新;增加 `--packaged` 可验证 `release/win-unpacked/resources/app.asar` 中的实际代码。

## 官方账户余额

- **查询来源**:固定请求 DeepSeek 官方 `GET https://api.deepseek.com/user/balance` 接口,不支持第三方中转服务余额。
- **展示内容**:账户是否可用,以及接口返回的人民币/美元总余额、充值余额和未过期赠送余额。
- **密钥来源**:自动按 Harness 的优先级解析启动环境、`$DSH_HOME/.credentials.yaml`、项目 `.env` 和用户 `.env` 中现有的 `DEEPSEEK_API_KEY`,页面不再要求重复输入。
- **安全说明**:API Key 只在主进程内解析并发送到 DeepSeek 官方接口,不会进入页面、日志或统计结果,桌面壳也不会额外保存副本。

此处“不保存副本”指余额功能。用户执行升级或插件变更时，完整数据/配置安全快照可能包含官方原有凭据；这些本机快照不属于可导出的桌面设置备份。

## 插件、通知与权限边界

- 插件和会话管理通过实际测试的官方 `0.1.7-rc.1` 本机接口适配，不直接改写官方数据库。旧版没有相应接口时会显示能力错误。
- npm 搜索结果不等于官方精选或安全审核。安装前必须通过官方插件识别；安装/启停/卸载会弹出本机确认，不自动批准依赖构建脚本。配置项继续使用官方页面。
- 会话“回到 Harness”在没有稳定直达接口时复制会话 ID 并打开主窗口。仅提供归档/恢复，不提供永久删除。
- 通知默认关闭；开启后应用驻留期间每分钟检查预算、余额和官方任务事件，支持免打扰及去重。关闭程序后不继续监控，不依靠日志更新时间猜测完成状态。
- 桌面管理 IPC 仅允许本应用登记的本地窗口和页面使用；官方 Web 页面及插件拿不到桌面管理权限。
- 费用方案只保存预算及价格，不切换模型、提供商、Key、插件或数据目录。多环境方案、远程实例和签名壳更新不在本版中。

## 常见问题

- **端口 3080 被占用**:在“更新与诊断”检查监听 PID；选择可用端口并重启，不会结束其他应用的进程
- **提示 30000ms 内未就绪**:这是 0.2.1 及更早版本等待时间过短造成的误判;升级桌面壳至 0.2.2 后会等待 120 秒并显示启动进度
- **Node.js 一键安装不可用**:该功能依赖 Windows 10/11 的 `winget`;请从 Microsoft Store 安装“应用安装程序”,或从 nodejs.org 手动安装 LTS
- **用量显示为 0**:先检查时间/模型/会话筛选及完整性状态；无记录、未完成索引和日志不兼容不是同一情况。必要时重建统计索引，不能通过删除会话日志“修复”
- **余额无法查询**:余额功能只支持 DeepSeek 官方 API Key。确认密钥有效、网络可访问 `api.deepseek.com`,并避免使用第三方中转服务的 Key
- **主窗空白**:dsh 服务正常时按 Ctrl+Shift+I 打开开发者工具查看报错(开发模式)
- **DSH_BIN/DSH_HOME**:首次接入时可显式指定。完成桌面壳托管版本切换后，会优先使用持久化的托管安装/数据副本，不再跟随全局 npm 安装变化
