# dsh-desktop v0.5.0

本版将桌面壳升级为分栏工作台，补齐用量、会话、插件、升级恢复及诊断功能。

## 下载与安装

- Windows x64 安装包：`dsh-desktop-setup-0.5.0.exe`。
- 校验文件：`SHA256SUMS-0.5.0.txt`。
- 等待当前任务结束，从托盘退出旧版后再安装。首次启动可引导安装 Node.js LTS 与官方 Harness。
- 安装包未做代码签名，请核对发布来源及 SHA-256。

## 新功能与优化

- **分栏工作台**：总览、用量与费用、会话、插件、更新与诊断、设置独立加载，支持浅色、深色及系统主题。
- **统计与计价**：默认今天；V0–V4 日志及增量索引；后台线程解压；历史价格、分时与节假日规则；按提供商/模型/生效时间自定义价格；未识别价格明确标为待定价。
- **预算与导出**：每日/月度预算、低余额和高费用会话提醒；前一等长时段对比；按筛选导出完整 CSV/JSON，不被分页截断。
- **会话管理**：本地名称、标签、项目分类、搜索、排序和费用详情；可选读取官方标题；归档/恢复使用官方接口。
- **插件中心**：真实插件清单、收藏、启停/卸载、npm 发现和版本检查；安装前官方识别，变更前备份配置。
- **可靠更新**：区分 npm 标签及 Alpha/RC 等通道；新版本独立安装；运行任务期间可延后更新；完整数据快照；恢复时保留升级后的数据；较低版本切换需再次确认。
- **运行诊断**：环境、端口/PID、目录、网络和脱敏错误分类；换端口重启、重新选择工作目录、导出报告；缺失快照时明确报错，不把空目录当作恢复成功。
- **桌面设置**：任务状态通知、免打扰、价格/预算方案，以及不包含 API Key 的桌面设置备份恢复。

## 验证与边界

- 88 项单元测试、TypeScript 检查、实际 ASAR 界面与主进程测试通过。
- 使用官方 Harness 0.1.7-rc.1 的独立测试环境验证启动、插件清单、工作区、会话归档/恢复和改端口重启；没有发送计费模型请求。
- 本机已有索引后的实测查询约 62–171 ms；首次索引仍需要时间，并在后台执行。不是所有设备上的性能保证。
- 插件发现不代表安全审核；第三方插件运行情况、全新 Windows 主机安装和系统通知仍需目标设备验收。
- 升级及插件配置快照可能包含原有凭据，仅保留在本机。恢复使用独立数据副本，不删除或自动合并新版数据；请预留磁盘空间。
- 费用方案仅切换价格和预算；完整多环境切换和桌面壳自身自动更新未启用。Harness 更新与桌面壳更新是不同功能。
- 统计为本机预估，不是官方账单；完整说明见 [0.5.0 交付说明](https://github.com/yanxi-lu/dsh-desktop/blob/v0.5.0/docs/release-0.5.0.md)。
