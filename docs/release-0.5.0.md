## 数据与安全说明

- 统计索引只保留用量与必要事件元数据，不存提示词、回答、工具参数、工作目录或密钥。
- 不认识的模型、代理 Provider、缺乏已核实价格的历史区间显示“待定价”；显示的费用只是已定价部分，不能当作完整账单。
- 价格规则版本 `2026-09-24.1`，随应用版本维护。依据：[定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[更新日志](https://api-docs.deepseek.com/zh-cn/updates/)、[9 月 10 日公告](https://api-docs.deepseek.com/zh-cn/news/news260910/)。官方日期/周末判断使用北京时间，统计筛选日期使用本机时区。
- 桌面设置导出不包含官方凭据，但本地填写的会话名称、标签等会包含在设置备份中。
- **升级全量快照与插件配置快照可能包含原有凭据**，仅存本机，不上传，也不夹带在设置导出中。请保护应用数据目录。
- 回退先复制升级前快照到新的数据目录，保留升级后的原目录；不删除、不自动合并两个版本的数据。磁盘需要容纳安装、快照与恢复副本。
- 不遍历外部或循环链接；仅支持将安全的内部目录链接重新定位到副本。遇到不支持的链接会中止备份，不冒险复制或删除。
- 所有桌面管理 IPC 验证本应用登记的窗口和本地页面。官方网页/第三方插件不能调用桌面管理接口。

1. TypeScript 编译与 88 项单元测试通过，覆盖历史计费、节假日、未定价、V4 compact stream、重试/分叉、完整性、导出、防公式注入、设置校验、通知去重、RPC 白名单、备份链接、缺失快照拒绝恢复和写盘失败时状态保持等。
2. 隐藏 Electron 窗口：80 个合成会话、2400 次调用，验证默认今天、分页、快速筛选合并、相同图表不重绘、空日期、设置持久化、标签搜索、单会话筛选与完整导出、收藏和诊断展示。此项使用合成业务数据，不是账户账单验证。
3. 真实日志只读性能测试：83 个日志文件（约 91.7 MB）、8173 次调用。已有索引查询约 62–171 ms；首次索引约 10–12 秒，后台统计期间主线程心跳最大间隔约 18 ms。这是本机单轮测量，不是跨设备 P95 保证。
4. 真实官方 0.1.7-rc.1、隔离空数据目录：验证 Electron 启动 Token 换 Cookie、会话清单、8 个插件清单、创建工作区、空白测试会话归档/恢复。没有发送计费模型请求。
5. 真实独立 npm 安装与恢复演练：目标版本启动通过、原全局安装未变化、旧快照在独立目录恢复、模拟迁移后的新数据保留。这是隔离夹具的升级机制验证，不是拿用户真实会话执行升级迁移。
6. 实际主进程联调：真实 Harness 启动、管理窗口 IPC、设置写盘、未授权窗口被拒绝、维护操作互斥、换端口后重启和重新认证后的插件接口通过。

## 明确不包含或需目标设备验收

- 源码提交到本项目仓库；Windows NSIS 安装包与校验文件通过本项目 GitHub Releases 交付，不上传到 DeepSeek 官方仓库。
- 未配置签名、所属发布源与桌面壳自身自动更新。Harness 的更新功能已实现，与壳自身更新是两件事。
- 费用方案只切换价格和预算；完整的模型/提供商/Key/插件/数据目录多环境切换、远程实例尚未实现。
- 插件配置项仍使用官方面板；npm 发现不是经过安全审核的精选市场。未替用户安装任意真实第三方插件，不能保证所有插件兼容。
- 没有稳定的官方会话直达接口时，“回到 Harness”会复制 ID 并打开主窗口；没有永久删除会话功能。
- 通知默认关闭、应用驻留期间每分钟检查，基于最近的官方任务状态；不是应用退出后的系统任务监控，不保证捕获轮询之间的每次瞬时状态。
- 离线时保留当前进程已加载的数据/版本结果；没有跨重启保存全部网络查询结果的离线数据库。
- 尚无自动删除旧安装或备份的空间清理策略；保留数据安全优先。
- 本轮未在无 Node 的全新 Windows 主机执行安装/卸载与 winget 提权，也未视觉验收 Windows 系统通知。目标主机的系统权限、代理、杀毒和插件运行情况仍需实机验证。
- 安装包未签名；校验和只能证明文件一致性，不等同于发布者签名。

## 复验入口

- `npm test`：单元测试。
- `npm run dist`：编译及本地 Windows NSIS 打包，发布配置禁用。
- `node scripts/check-usage-performance.cjs`：只读本机日志性能回归；仅清理本次生成的临时索引。
- `electron scripts/smoke-usage-ui.cjs --packaged`：实际 ASAR 中的渲染器、预加载和统计 Worker 验证。
- `electron scripts/smoke-desktop-main.cjs <已安装的dsh.cmd绝对路径> --packaged`：实际 ASAR 主进程、隔离真实 Harness、IPC 和重启验证。
- `node scripts/check-official-bridge.cjs <官方lib/bin.js绝对路径>`：隔离官方接口验证，不发送模型请求。
- `node scripts/check-managed-install.cjs 0.1.7-rc.1`：需要联网的独立安装和快照恢复演练。

Windows 下 Electron 是 GUI 进程，自动化复验需要使用 `Start-Process -WindowStyle Hidden -Wait -PassThru` 等方式等待并检查退出码，不能把命令立即返回当作测试完成。
