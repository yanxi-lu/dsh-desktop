# 0.5.1 交付说明

日期：2026-09-24。本版本仅作本地构建，未单独发布；以下改动随 [0.5.2](release-0.5.2.md) 交付。

## 变更

- 左侧导航使用固定 180px 宽度、独立图标列和单行标签，取消窄窗口下收缩到 132px 的规则；底部说明也保持整行。
- 移除“恢复升级前快照”按钮及对应 IPC，不再生成 Harness 升级数据快照。
- 新安装仍先独立下载并校验。服务启动成功后，只保留当前托管安装；旧版需要从官方版本列表重新下载安装，不复用历史安装目录。
- 降级保留兼容性确认：继续使用原数据目录，旧版本未必能读取新版数据，重要数据需自行备份。
- 下载失败或取消清理本次暂存目录。切换开始后不可中断；启动失败可重试或重装，不自动把可能已经迁移的数据交给旧版运行。
- 清理仅限确认归属的非当前 UUID 安装目录；拒绝路径越界、数据目录重叠和链接。失败立即停止自动重试，需用户检查并明确确认后重试。
- 不卸载系统全局 npm 安装，不删除会话、配置、旧数据快照或插件配置备份。兼容 0.5.0 状态，保留当前数据目录，包括正在使用的 restored-data。

## 验证

- TypeScript 编译和 98 项单元测试通过，覆盖版本重装、旧安装清理、遗留状态迁移、失败/取消、Windows 短路径、数据与链接保护。
- 隐藏 Electron UI 回归通过：80 个合成会话、2400 次调用，保留原有统计、分页、设置、导出等回归；验证 820/1040/1280 宽度与 100%/125%/150% 缩放的 9 种组合，六个菜单均为单行且没有截断。

- 真实官方 npm 0.1.7-rc.1 两次独立下载安装、两次实际启动通过；重装后仅剩当前安装目录，原全局版本未变，模拟升级后的数据保留，没有创建升级快照。
- 源码主进程联调通过：真实 Harness 启动、8 个插件接口、设置持久化、非授权 IPC 拒绝、维护互斥、换端口重启；携带 0.5.0 缺失快照指针的状态正常迁移，当前数据目录不变。

- 最终 ASAR 的页面回归通过（合成数据首次加载 505 ms），9 种导航尺寸/缩放组合均通过；包内实际主进程与真实 Harness 的启动、IPC、重启、旧状态迁移回归通过。
- ASAR 内 56 个本地源文件/构建文件逐字节一致，包内版本为 0.5.1。

测试只使用隔离临时目录；不使用用户 Key、不进行计费模型调用。未替用户关闭正在运行的程序、安装新壳或操作真实会话，未在另一台 Windows 电脑验收。
